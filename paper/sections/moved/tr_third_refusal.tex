\begin{remark}[A third kind of refusal]\label{rem:third-refusal}
The last case of Theorem~\ref{thm:arith} is a refusal of a kind \S\ref{sec:gaps} does not
have a column for. It is not a gap in PromQL, which expresses the pairing perfectly well
once asked, and it is not unfinished work here. It is a query with no source denotation:
Datadog declines to answer it. A translator cannot preserve a meaning the source system
does not assign, so the right behaviour is to refuse, and the right accounting is to
exclude it from both sides of the ledger rather than to count it against either language.
No corpus query reaches it, so nothing in \S\ref{sec:gaps} moves; the case is recorded
because the distinction is the one this paper is about and it would otherwise be filed
under ``unimplemented'' by default.

The subset case is the opposite kind of correction. An earlier version of this emitter
admitted only $\overline{k_r}=\emptyset$ and refused every other containment, which would
have been counted as unfinished work --- correctly, since the measurement shows PromQL
says it with \texttt{on($\overline{k_r}$)} and Datadog accepts it. Measuring the boundary
moved one case out of the catalogue and sharpened the other.
\end{remark}
